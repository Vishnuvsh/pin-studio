## ✨ Features at a Glance

### 🛍️ E-Commerce Sales Boosters
- **Product Price Badge**: Display sale price (e.g. `₹499`, `$29`), crossed-out original price (`₹999`), and discount pill (`50% OFF`).
- **4 Badge Styles**: Pinterest Red, Golden Luxury, Dark Onyx, and Clean White Card.
- **Shop CTA Buttons**: Eye-catching 3D pill buttons (`SHOP NOW ➔`, `BUY NOW 🛍️`, `GRAB 50% OFF ⚡`, `LINK IN BIO 🔗`) with soft glow lighting.

### 🪄 Smart Description Converter (AI Copy Assistant)
- **Paste raw product notes** or vendor descriptions.
- **Select your marketing tone**:
  - 🔥 *Viral Hook & Trend*
  - 💎 *Luxury & Aesthetic*
  - ⚡ *Urgency & Massive Deal*
  - 🌿 *Clean & Benefit-Focused*
- **1-Click Apply**: Instantly applies headlines and subheadlines to the live canvas preview. Auto-detects prices and discounts!
- **SEO Caption & Hashtags**: Generates search-optimized captions with targeted trending Pinterest tags ready to copy in one click.

### 📐 Pinterest-Optimized Canvas Engine
- **Standard Ratios**: 2:3 Pinterest Pin (1000×1500), 9:16 Story/Reels (1080×1920), 1:1 Square (1080×1080).
- **Display Modes**: "Crop to Fill" cover mode or "Blur Backdrop" mode.
- **Interactive Drag & Pan**: Drag to reposition the image directly on the live canvas with zoom control.
- **Aesthetic Filters**: Original, Warm, Vibrant, Moody, and B&W.
- **Watermark & Brand Tag**: Add your store URL (`yoursite.com`) and custom badge (`MUST TRY`, `HOT DEAL`).
- **1-Click High-Res Export**: Instant `.jpg` download ready to post.

## 🛠️ Tech Stack

- **Vanilla JavaScript (ES6+)**: Fast, zero framework overhead, no build tools required.
- **HTML5 Canvas 2D API**: High-resolution image composition and typography rendering.
- **Tailwind CSS**: Modern, responsive user interface.
- **Google Fonts**: Plus Jakarta Sans, Playfair Display, Inter, and Dancing Script.

---

## 📦 How to Use Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Vishnuvsh/pin-studio.git
   cd pin-studio
   ```
2. Open `index.html` (or `demo.html`) in any modern web browser.
3. Upload an image, customize your sale tag, generate copy, and click **Download Pin**!
